# Araña de Multiserveis d'Aro

Web para el móvil con tres modos:

- **Documentos:** pega un texto o sube un PDF y la araña saca el resumen, las ideas importantes, fechas, importes, cantidades, personas, contactos y tareas.
- **Presupuestos:** describe el trabajo y se monta el presupuesto con la tarifa de la empresa (editable en la propia web, se guarda en cada móvil).
- **Tiendas:** busca en un mapa interactivo las tiendas cercanas que venden un producto (datos de OpenStreetMap) y enlaces para buscarlo en internet.

Funciona sin cuentas ni servidor: todo se procesa en el propio navegador. Se puede añadir a la pantalla de inicio del móvil como una app.

Se publica con GitHub Pages desde la rama `main`.

Librerías incluidas en `lib/`: [Leaflet](https://leafletjs.com) y [PDF.js](https://mozilla.github.io/pdf.js/) (licencias en la misma carpeta). Mapas y tiendas: © colaboradores de [OpenStreetMap](https://www.openstreetmap.org/copyright).
